## Description

- **[R_Reconstruction](ca://s?q=R_Reconstruction_folder_usage)**: Contains the main script (`Belize RSL Main Script.Rmd`) encompassing the RSL reconstruction and consolidated modelling results alongside supporting data, figures, and results.
- **[MATLAB_ESTGP](ca://s?q=MATLAB_scripts_and_data)**: Script, data, figures and results associated with the spatiotemporal empirical hierarchical Gaussian Process model (EST-GP) (Ashe et al., 2019).
- **[R_reslr](ca://s?q=Python_scripts_and_data)**: Scripts, data, figures and results associated with the reslr package (Upton et al., 2025) used to run the Errors-In-Variables Integrated Gaussian Process (EIV-IGP) model and Noisy-Input spline (NI-spline) models. 
- **[README.md](ca://s?q=Documentation_folder_structure)**: This README file explaining folder and file structures.
---

## Notes

- Data files are separated by language to avoid conflicts.
- Figures and results generated by the scripts are stored in dedicated subfolders for reproducibility.
